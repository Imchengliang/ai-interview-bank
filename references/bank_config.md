# 题库配置

## 当前题库路径

由 `config.json` 的 `bank_path` 决定，默认：

```
~/Documents/interview/ai_question.md
```

`~` 会展开为当前用户的家目录；相对路径按包根目录解析。这是唯一真源文件，所有读取、去重、写入都指向它。首次 `init` 会生成 `config.json`，之后以它为准（本文件不再记录具体路径）。

## 路径迁移

若用户指定了新的题库位置：

1. 移动现有 `ai_question.md` 到新路径（保留全部历史条目与编号，不重建）。
2. 把 `config.json` 的 `bank_path` 改为新路径。
3. 若用了 `scripts/list_questions.py` 的默认值，用 `--path` 显式传入新路径即可。
4. 在题库「更新日志」记一行迁移说明。

迁移前先确认新路径下不存在另一份题库；若存在，先向用户确认合并方式，绝不自动覆盖。

## 文件结构约定

| 段落 | 作用 | 编辑方式 |
|------|------|----------|
| `## 类别` | 13 个固定类别表 | 仅在确实装不下时新增类别 |
| `## 题库` → `### N. 类别` | 按类别存放题目条目 | 只追加条目、只补答案 |
| `## 题目条目格式` | 条目模板（示例代码块） | 只读，不改 |
| `## 关联索引` | 题目之间的关联清单 | 每批写入后更新 |
| `## 更新日志` | 每次写入的日期、来源、数量 | 追加一行 |

## 条目字段

```
#### Qxxx · 类别名 · 状态：待分析 | 已分析
**题目**：题干原话
**关联**：Qyyy（差别一句话）；无关联写「无」
**考什么**：一句话
**解题思路**：2–4 步编号列表
**参考答案**：3–6 句口语化回答
```

- 编号格式 `Q` + 至少三位数字，全局递增、只增不复用。
- 状态只有 `待分析` / `已分析` 两种。
- 题库不记录逐题来源（链接、图号、日期）；批次信息只写在「更新日志」。
- 帖子自带的参考答案只作校验素材，不写入题库条目；答案必须按流程独立分析后写入。

## 编辑禁忌

- 不改写、不删除已有题干；发现原题干有歧义时用括注补充，不覆盖。
- 不在多个位置重复存同一道题；变体并入原条目。
- 不为每批帖子新建文件；不把题库拆成多个 markdown。
- 不把「题目条目格式」示例代码块里的 `Q001` 当成真实题目（解析脚本已跳过代码块）。
